# 校园查寝自动签到

山东协和学院"智能查寝"签到辅助工具，有电脑版和安卓版两个版本。

学校要求 21:30 到 22:30 之间、在宿舍楼下 30 米范围内点签到。这个工具直接调用学校接口提交打卡点坐标，
不需要开浏览器、不需要开定位，一次签到不到 1 秒。

仅供个人使用，请勿传播。因使用本工具产生的一切后果由使用者自行承担。

---

## 两个版本

电脑版是带图形界面的 Python 程序，能管多个账号，适合平时电脑常开的情况。
安卓版是一个 80KB 的 APK，装手机上到点自己签，不用开电脑。

同一个学号不要两个版本同时用。学校对同一账号的会话有限制，一边登录可能把另一边挤下线。

## 电脑版

### 环境

需要 Python 3.9 或更高版本（3.8 不行，Playwright 要求 3.9 起）。依赖只有四个：

```
pip install -r pc/requirements.txt
python -m playwright install chromium
```

Chromium 约 150MB，装一次就行。下载慢的话可以先设置镜像：

```
set PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright
```

如果装 Playwright 时 greenlet 要现场编译、机器上又没有 C 编译器，加上 `--only-binary=:all:` 让它走预编译包。

### 启动

```
python pc/app.pyw
```

第一次运行会在 `pc/` 下生成一个 `协和查寝.lnk` 快捷方式，之后双击它就行。
程序做了单实例保护，重复打开只会把已有窗口调到前面。

### 添加账号

点"添加账号"，填学号和密码，点"打开登录窗口"。之后**全自动**：程序在后台开一个看不见的
浏览器，自己切到"账号登录"、填账号密码、勾"7天免登录"、识别滑块缺口并拖过去，
登录成功后拿到 Cookie 关掉窗口。整个过程窗口不会弹出来，大约 20 秒。

如果自动登录失败（比如密码填错，或者滑块连试几次都没过），会自动改成弹出可见窗口，
这时手动拖一下滑块就行。

密码用 Windows 自带的 DPAPI 加密后存在本地数据库里，只能在这台电脑的这个 Windows
账户下解开。保存它是为了让 Cookie 过期后能自己重新登录，不用再管。

有第二个账号就再点一次"添加账号"。同一个学号不会重复添加，只会更新登录状态。

### 关于滑块

学校登录强制滑块验证。程序的做法是：从背景图里识别出被挖掉的拼图缺口，然后用带垂直抖动的
拟人轨迹拖过去。实测连续 8 次全部通过。

原理写在 [docs/api.md](docs/api.md) 里，简单说就是页面里那个 `inst.x` 是前端随机数、
不是答案，照着它拖必然失败，得从图片里算。

### 签到

选中账号点"签到"只签一个，点"一键签到"按顺序签全部，账号之间会等设定的秒数（默认 3 秒）。
列表里每个账号显示名称、学号、宿舍、当前状态、上次签到时间和最近一次的结果原因。

### 定时

勾上"每天自动签到"并设置时间（默认 21:30），到点自动开始。没签上就每 60 秒重试一次，最长 45 分钟。

定时依赖程序一直运行，窗口不能关，可以最小化。要关机也能签就用安卓版。
"开机自动启动"会在启动目录放一个快捷方式。

### 缓存和日志

日志在 `pc/data/app.log`，界面上可以查看、清除、导出。清除缓存和清除日志都会先弹确认框。

## 安卓版

APK 在 `android/dist/`，传到手机点开安装。vivo 和 iQOO 会弹一个"安全守护"提示，
勾选"已了解应用的风险检测结果"再点继续安装。

安装后按顺序做四步：

1. 点"登录/添加账号"。如果之前在电脑上填过，这里也一样：登录页自动填账号密码、自己拖滑块，
   几秒到十几秒就登进去了。万一滑块没过，手动拖一下就行
2. 点"允许通知""允许精确闹钟""忽略电池优化"，三个都同意
3. 打开"定时自动打卡"开关，副标题显示"已开启：每天 21:20 自动签到"就生效了
4. 有第二个账号就再点一次"登录/添加账号"

多账号页面可以对单个账号签到，也可以一键签全部，账号间隔可以调（0 到 120 秒）。
点账号名可以给这个账号重新登录，不用删掉重建。

每个账号的状态、上次签到时间、失败原因都会显示在列表里。

### 签到日历

主界面点「签到日历」，按月份看每天的签到情况：

- 绿色：那天签上了
- 红色：缺勤（过去没签的；只从有记录的第一天开始算，之前的日子不标）
- 蓝框：今天（今天没签也是浅灰底 + 蓝框，方便一眼找到）
- 浅灰：还没到

底部会统计「本月已签 N 天　缺勤 N 天」。

顶部可以切月份、按账号筛选。点某一天能看到那天几点签的、用的哪个位置。

「导入学校的考勤记录」会把最近 6 个月的学校考勤拉下来写进日历（接口 `getKqlsList.do`，
传 YEAR/MONTH，返回整月每天，只有签过的才有时间和地点），换手机或重装后点一次就补齐了。

### 签到位置

优先级从高到低：

1. **账号单独设置的位置**：账号列表每行的「位置」按钮，可以只给这个账号指定打卡点
2. **主界面的默认位置**：对所有没单独设置的账号生效
3. **自动**：沿用这个账号上一次签到成功的位置；一次都没签过就按宿舍名在学校给的打卡点列表里匹配

签到提交的是「名称 + 纬度 + 经度」，服务端按它和打卡点的距离算，30 米内有效，提交前会随机偏移 ±3 米。

「位置」弹窗里可以直接填名称和经纬度，也可以点「从学校的打卡点列表里选」，挑一个自动填进去；
「恢复自动」就回到按上次位置/宿舍匹配。

### 存储占用与清理

App 占的空间大头不是账号数据，而是登录网页的内核文件：`app_webview` 里有一个 4MB 的
`BrowserMetrics-spare.pma`，还有 Cache、Code Cache、Service Worker 这些目录，每登一次都会往里写。

「清除缓存」会连 `app_webview` 一起清（实测 4.5MB → 0.3MB），不会动账号、密码和签到记录。
运行日志也设了 128KB 上限，超过就只保留最后一段，不会无限增长。

### 网络与出口 IP

主界面点「网络 / 出口 IP」可以检测当前出口 IP、归属地和运营商。
下面可以填代理列表（一行一个 `host:port`），填了之后本应用的请求都走代理，等于换了出口 IP。
填多个代理时，每签一个账号自动换下一个，适合多账号各走各的 IP。留空就是直连。

### 一键重新登录

主界面「一键重新登录」：把所有存过密码的账号排好队，逐个自动登录（自动填表、自动过滑块），
每个大约 10 秒，全程不用操作。登录完只刷新状态，不会顺手签到。

### 定时打卡遇到登录失效

到点自动打卡时如果发现会话过期了，会先在后台用保存的密码自动重登一次，成功后接着把这次打卡做完；
重登失败（密码改了、账号被锁、网络不通等）就记下原因、发一条通知，并停下这次打卡，不会带着失效状态硬签。

后台重登要把登录网页挂在一个几乎透明的悬浮窗上才能跑起来，所以需要一次授权：
主界面「授权与保活」里的「允许后台自动登录（悬浮窗）」，打开「显示在其他应用上层」即可。
没授权也能用，只是失效时会退化成"发通知点一下"的方式。

### 密码与自动重登

登录时输入的密码会用 Android 系统密钥库（Keystore）加密后存在本机数据库里，密钥不出系统安全区，
数据库里只有密文。卸载重装或换机会读不出来，那就重新登录一次。

Cookie 过期时不用管：点"立即签到"会先查一次登录状态，发现失效就用存好的密码自动重登（同样自动过滑块），
登完接着把签到做掉。后台定时任务遇到同样情况也会自己拉起登录页，登完继续签。

账号管理里长按某个账号可以改学号和密码，改完会立刻用新密码自动登录一次。顶部的"刷新状态"是真的去问服务器，
不是刷新文字——它会告诉你每个账号现在是"已登录 / 未到时段 / 已签到 / 登录失效"。

### 后台保活

国产系统的省电策略会杀掉后台，需要单独设置：

- 小米、Redmi：设置里的自启动打开，省电策略改成无限制，任务卡片下拉锁定
- 华为、荣耀：应用启动管理改成手动管理，三个开关全开
- OPPO、一加、realme：电池里的应用速冻或耗电保护，允许后台运行
- vivo、iQOO：电池里的后台耗电管理，允许后台高耗电

App 里的"忽略电池优化"按钮点了之后，大部分情况就够用了。

## 工作原理

学校的签到页面本质上是两个接口：

```
POST /xsfw/sys/swmzncqapp/kqController/getKqInfo.do
  data={}
  返回签到时段、今天是否已签、所有打卡点的经纬度和允许半径、自己的宿舍

POST /xsfw/sys/swmzncqapp/kqController/addKqInfo.do
  data={"KQWZXX":"打卡点名称","JDZB":"经度","WDZB":"纬度"}
```

页面上的签到按钮是灰色的，因为前端用地图算当前位置到各打卡点的距离，超出半径就置灰。
程序直接把打卡点坐标（加几米随机偏移）提交上去，等同于人在楼下。

详细字段和登录流程见 [docs/api.md](docs/api.md)。

## 常见问题

**提示"登录已失效"**
程序会先用保存的密码自己重新登录一次，成功了就继续签到。只有在没存密码或者自动登录也失败时，
才会提示需要手动处理，这时在账号列表点该账号名，重新走一次登录即可。

**点添加账号后卡了很久**
自动登录要开浏览器、过滑块、等跳转，正常 20 秒左右。如果超过 1 分钟还没有结果，
说明滑块连续几次都没通过，程序会自动弹出可见窗口让你手动拖。

**提示"用户名或密码不正确"**
填的密码不对。重新点"添加账号"（或选中账号点"重新登录"）输入正确密码。

**提示"不在签到时段"**
正常。签到窗口是 21:30 到 22:30，定时签到会自动等到窗口开启再提交。

**提示"没匹配到打卡点"**
宿舍信息变了，或者学校改了打卡点名称。导出日志看一下返回的打卡点列表，据此调整
`pc/core.py` 里的 `pick_point()`。

**手机上好好的，电脑上突然失效**
两边不能同时用同一个账号。日常选一个用。

**电脑版关掉之后没有自动签**
定时依赖程序运行，窗口不能关。要关机也能签就用安卓版。

**到点没动静（安卓）**
先确认"定时自动打卡"开关是开着的，再检查上面那节的后台保活设置。也可以点"立即签到"看手动能不能通。

## 重新构建安卓版

安卓版没有用 Gradle 和 AndroidX，全部走 framework API，用命令行直接打包：

```
cd android
python build.py
```

脚本依次执行 aapt2 编译资源、javac 编译、d8 转 dex、zipalign 对齐、apksigner 签名。
第一次运行会自动下载 build-tools 和 platform（约 120MB）到 `android/tools/`，之后每次出包几十秒。
